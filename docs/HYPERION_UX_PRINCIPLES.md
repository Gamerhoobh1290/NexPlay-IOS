# Hyperion UX Principles

1. NexPlay must remain friendly and easy to master.
2. Hyperion OS is a media environment, not a literal operating system.
3. Settings should stay understandable.
4. Presets should feel intentional, not mysterious.
5. Focus mode may reduce visuals, but it must never feel like broken CSS.
6. Advanced features should feel approachable.
7. The app should not become developer-facing or overly technical.
8. The user experience is not the problem; developer maintainability is the problem.
